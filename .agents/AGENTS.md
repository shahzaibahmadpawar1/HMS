# Project Rules

## Supabase SQL Requirements
Whenever a database schema change is required or a new table/column is added, you MUST provide the exact Supabase SQL query required to make that change. The user will execute these queries in their Supabase SQL editor.

## Software Name
The name of this software is "CareNexus". Do not use "OPDPRO" or any other name. Always refer to it and brand it as "CareNexus" in UI, text, and documentation.
